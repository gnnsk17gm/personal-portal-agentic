# ADR 0017: iPhone風リアルタイム並び替え（@dnd-kit/sortable）と長押し編集モードの採用

- **ステータス:** Accepted (採択)
- **決定日:** 2026-11-23
- **決定者:** Project Architect

## 1. コンテキスト (Context)
Spec 018・019 では HTML5 標準 Drag & Drop と「編集ボタン＋矢印ボタン」によるカスタマイズを実装したが、日常的な操作感として以下の課題があった：
1. ドラッグ中に周囲のタイルがリアルタイムで避けるアニメーション（FLIP / Transform遷移）がなく、移動先が直感的に分かりづらい。
2. 「編集」ボタンを押すワンアクションが必要であり、また移動用の矢印ボタンがUI上のノイズになる。
3. タッチデバイス（タブレット・スマホ）での長押しドラッグに対応していない。

## 2. 検討した選択肢 (Options Considered)
- **Option 1: 自前で Pointer Events と FLIP アニメーションエンジンをスクラッチ実装する**
  - 2次元グリッド（3列）でのリアルタイム位置計算とアニメーション補間のエッジケースが多く、保守コストが高い。
- **Option 2: `@dnd-kit/core` + `@dnd-kit/sortable` + `@dnd-kit/utilities` の導入 + 長押し検知**
  - 軽量・モダンな DnD ツールキットであり、`rectSortingStrategy` により3列グリッド上で他のタイルが滑らかに避けるアニメーションを標準提供し、マウス・タッチの両方に対応できる。

## 3. 決定内容 (Decision)
**Option 2（`@dnd-kit/sortable` の導入 + タイル長押し開始 / 背景クリック終了 UX）を採用する。**
（※ADR 0016 の外部依存ゼロ方針は本UI要件のため改定し、純粋関数群 `dashboardTiles.ts` と Cookie 永続化アーキテクチャはそのまま継承する）

## 4. 結果とトレードオフ (Consequences)
- **メリット (Positive):**
  - iOSホーム画面のような滑らかな並び替えアニメーションと直感的な長押し編集が実現する。
  - 矢印ボタンや「編集」ボタンをUIから排除でき、普段使いの画面が極限までシンプルになる。
- **トレードオフ (Negative):**
  - `@dnd-kit/*` パッケージが依存関係に追加される（SSR でのハイドレーション不一致を防ぐため、`DndContext` に固定 `id` を付与する）。
