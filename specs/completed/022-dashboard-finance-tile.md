# Spec 022: ダッシュボード家計簿正方形タイル（Finance Tile）の実装

* **ステータス:** Draft / Ready for Implementation
* **関連 ADR:** `docs/adr/0016-dashboard-tile-customization.md`, `docs/adr/0017-iphone-style-tile-editing.md`, `docs/adr/0018-finance-module-and-recurring-snapshot.md`
* **前提 Spec:** Spec 018〜021
* **対象ブランチ:** `feat/home-finance-tile`（`main` から分岐）

## 1. 目的と概要

ホームダッシュボード（`/`）の 3 列正方形タイルグリッドに、家計簿サマリーとカテゴリ別内訳をひと目で把握できる **「Finance（家計簿）タイル」** を追加する。
既存の iPhone 風タイル編集機能（長押し編集モード・ドラッグ並び替え・削除バッジ・追加スロットからの再追加）に完全統合し、基本モード（`standard`）・ポートフォリオモード（`portfolio`）の双方で一貫した操作体験を提供する。

## 2. 機能要件

### 2.1 タイル表示レイアウト（1:1 正方形カード内）

タイル内は「余白クリックで `/finance` へ遷移」する既存ルールに従い、以下の情報を 1:1 正方形カード内にバランスよく配置する。

1. **ヘッダー行:**
   * アイコン（`Wallet`）＋ タイトル `Finance` ＋ 右端に小さく対象年月（例: `2026-11`）または `詳細 >` ヒント。
2. **上段エリア（今月の支出合計 ＆ 予算プログレスバー / 収支バランス）:**
   * **今月の支出合計:** 大きく視認性の高いフォントで `¥XX,XXX` を表示。
   * **月間総予算が設定（または過去月から継承）されている場合:**
     * 右側または下部に `予算残り ¥XX,XXX`（超過時は `-¥XX,XXX` を警告色で表示）と消化率プログレスバーを表示。
   * **月間総予算が未設定の場合:**
     * 予算プログレスバーの代わりに、今月の **収支バランス（`+¥XX,XXX` / `-¥XX,XXX`）** を表示。
3. **下段エリア（ミニドーナツグラフ ＆ 上位カテゴリ凡例）:**
   * **左側:** 純粋 SVG によるコンパクトなミニドーナツグラフ（支出 0 円時はグレーのプレースホルダーリングを表示）。
   * **右側:** 支出金額上位 3 カテゴリのコンパクト凡例（カテゴリ色ドット・カテゴリ名・構成比 `%`）。4 カテゴリ以上ある場合は必要に応じて `他 ●件` を控えめに表示。

### 2.2 データ取得と当月固定費の自動計上連携

* ダッシュボード（`/`）の Server Component で当月（`YYYY-MM`）のサマリーデータを取得する際、`ensureRecurringTransactionsForMonth`（当月オンデマンド自動計上）を呼び出してから集計することで、`/finance` を開く前でもダッシュボード上に当月の固定費込みの最新支出・残予算が反映されるようにする。

### 2.3 タイルカスタマイズ・編集モード統合（Spec 018〜020 準拠）

* **タイル ID:** `'finance'` をダッシュボードタイル定義に追加する。
* **デフォルト配置:** デフォルト表示タイル一覧に `'finance'` を含める（新規ユーザーや Cookie 未設定時に初期表示される）。
  * ※ すでに Cookie（`dashboard_tiles`）にカスタム配置を保存済みのユーザーに対しては、既存の編集結果を破壊せず、「＋ タイルを追加」スロットの候補リストから `'finance'` を追加できるようにする（または未登録タイルとして選択肢に表示する）。
* **編集モード挙動:**
  * 長押し（500ms）で編集モードに入り、他のタイルと同様にドラッグ＆ドロップ並び替え、左上 `×` バッジでの非表示化、「＋ タイルを追加」からの再追加ができること。
  * 編集モード中は `/finance` への遷移を無効化する（既存タイルと共通仕様）。

### 2.4 デザイン・モード制約

* ライトモード基調（白背景・スレート枠線・明確なコントラスト）を厳守する。
* 基本モード（`standard`）では AI 関連の表現・ラベルを一切表示しない。

## 3. アーキテクチャ & ファイル構成案

* `src/lib/dashboard-tiles.ts`（または既存のタイル定義管理モジュール）: タイル ID `'finance'` の型定義・メタデータ・デフォルト配列および追加候補リストへの登録。
* `src/lib/finance.ts`: ダッシュボード表示用の軽量サマリー取得関数（今月支出・収入・収支・有効予算額・上位カテゴリ内訳をまとめて返す関数）の追加（既存関数の組み合わせでも可）。
* `src/components/dashboard/FinanceTile.tsx`（または既存タイルコンポーネント群の配置ディレクトリ）: 1:1 正方形タイル UI およびミニドーナツグラフ SVG コンポーネント。
* `src/app/page.tsx`（およびダッシュボードグリッドコンポーネント）: `'finance'` タイルのデータ供給とレンダリング分岐の追加。

## 4. 受け入れ基準（Acceptance Criteria）

1. ホームダッシュボード（`/`）に `Finance` 正方形タイルが表示され、今月の支出合計、予算残り＆プログレスバー（未設定時は収支バランス）、ミニドーナツグラフ＆上位カテゴリが表示されること。
2. `Finance` タイルの余白クリックで `/finance` へ遷移できること。
3. 長押し（500ms）による編集モードで、`Finance` タイルの並び替え・削除（非表示）・「＋ タイルを追加」からの再追加がすべて正常に動作し、Cookie に永続化されること。
4. 支出 0 円の状態および予算未設定・設定済み・予算超過のいずれの状態でもレイアウト崩れや NaN 表示が起きないこと。
5. `npm run verify`（ESLint + TypeScript `tsc --noEmit` + Vitest）がエラー 0 件でパスすること。

## 5. テスト計画（Vitest）

* ダッシュボード用サマリーデータ整形ロジックのユニットテスト（支出 0 円、予算未設定時の収支バランス切替、予算超過時の残額計算、上位 3 カテゴリ抽出など）。
* タイル設定パーサー / デフォルトタイル一覧に `'finance'` が正しく組み込まれていることの検証テスト。
